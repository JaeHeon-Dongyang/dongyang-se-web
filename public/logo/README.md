# 동양구조엔지니어링 로고 웹 에셋

## 권장 사용

- 헤더·푸터 가로형 로고: `dongyang-full.webp`
- 고해상도 또는 PNG가 필요한 곳: `dongyang-full-2400.png`
- 심벌 단독 사용: `dongyang-symbol.svg`
- 앱 아이콘: `dongyang-symbol-512.png`
- Apple Touch Icon: `dongyang-symbol-180.png`
- Favicon: `dongyang-symbol-32.png` 또는 `dongyang-symbol-48.png`
- 흰 배경 문서용: `dongyang-full-white-2400.jpg`

## 작업 사항

- 원본의 흰색 배경을 제거해 투명 배경으로 변환
- 심벌과 한글 상호의 원형 보존
- 영문 표기의 `Strustural`을 `Structural`로 교정
- 영문 표기를 DWG 원본에 따라 `Dongyang Consulting & Structural Engineers Co.,LTD`로 재조판
- 브랜드 녹색을 `#0B6C43`으로 적용
- 표준형, 단색 녹색형, 어두운 배경용 흰색형 제공
- 가로형 로고를 1200px, 2400px, 3600px 너비로 제공
- 심벌을 SVG 및 주요 웹 아이콘 크기로 제공

## 주의

- 가로형 로고는 원본 한글 로고타입을 보존한 고해상도 래스터 에셋입니다.
- 심벌 SVG는 원본의 단순 기하학을 기준으로 재구성한 벡터 에셋입니다.
- 공식 영문 법인명 표기가 별도로 있다면 영문 문구를 최종 확인한 뒤 사용하세요.
