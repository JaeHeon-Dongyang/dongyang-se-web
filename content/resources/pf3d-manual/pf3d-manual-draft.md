# PF3D 사용 매뉴얼 초안

## PF3D를 활용한 성능기반 내진설계 업무 흐름

이 매뉴얼은 성능기반 내진설계를 처음 수행하는 사용자가 기존 구조해석 모델을 정리하고, PF3D 입력자료를 생성하며, 해석 결과를 보고서 자료로 정리하는 전체 흐름을 이해하도록 돕기 위한 안내서입니다.

기존 K Design 중심의 작업 대신 동양구조엔지니어링에서 개발한 다음 프로그램을 기준으로 설명합니다.

- PF3D Pre Processor v4.02
- PF3D Post Processor v10.03
- AutoHotkey 기반 반복작업 자동화 도구

이 문서는 전체 작업의 순서와 각 단계의 목적을 간략히 설명하는 초안입니다. 프로그램 화면, 입력 예시, 명명 규칙, 검토 기준과 오류 해결 방법은 추후 실제 프로젝트 자료와 화면 캡처를 추가하여 보완합니다.

> 주의: 본 매뉴얼은 사내 업무 흐름을 정리한 사용 안내서입니다. 실제 설계 판단, 적용 기준, 해석 조건과 결과 검토는 담당 기술자의 확인을 받아야 합니다.

---

# 1. 전체 작업 흐름

PF3D 작업은 다음 순서로 진행합니다.

```text
ADS 모델 준비
→ ADS에서 Gen용 MGT 파일 출력
→ Midas Gen 모델 정리 및 검토
→ MGTX/MGT, Story Mass, BeST Wall List 준비
→ PF3D Pre Processor v4.02 실행
→ PF3D 입력자료 작성
→ AutoHotkey 보조작업 수행
→ 비선형 모델과 해석조건 검토
→ 지진파 및 횡하중 가력패턴 입력
→ PF3D 해석 실행
→ 결과 TXT·PDF Export
→ PF3D Post Processor v10.03 실행
→ 그래프·검토표·보고서 자료 확인
→ 최종 기술자 검토
```

작업을 시작하기 전에 프로젝트 폴더, 프로그램 버전, 입력자료와 파일명 규칙을 확인합니다. 기존 파일은 별도로 백업하고, 변환 전 모델과 PF3D 작업 모델을 구분하여 보관합니다.

# 2. 작업 전 준비

## 2.1 필요한 프로그램

- ADS
- Midas Gen
- Perform-3D
- BeST
- PF3D Pre Processor v4.02
- PF3D Post Processor v10.03
- 지정된 AutoHotkey 실행파일 또는 스크립트
- 프로젝트별 매크로 작업용 Excel 파일

## 2.2 필요한 입력자료

- ADS 원본 모델
- ADS에서 Export한 Gen용 MGT 파일
- 정리된 Midas Gen 모델과 MGTX 또는 MGT 파일
- Midas Gen Story Mass Table
- BeST Wall List 파일
- 구조도면 및 부재 정보
- 지진파 입력자료
- 횡하중 가력패턴 자료
- 프로젝트별 설계조건과 검토기준

## 2.3 폴더와 파일명

프로젝트별로 원본, 전처리, PF3D 모델, 해석 결과, 후처리 결과와 보고서 폴더를 구분합니다.

예시:

```text
프로젝트명/
├─ 01_원본모델
├─ 02_Gen변환
├─ 03_전처리
├─ 04_PF3D모델
├─ 05_해석결과
├─ 06_후처리
└─ 07_보고서
```

기존 작업 기준에 따라 PF3D 모델 파일명은 동 또는 대상 모델을 식별할 수 있도록 일관되게 작성합니다.

> 추후 추가: 사내 표준 파일명 규칙과 실제 예시.

# 3. ADS에서 Gen 파일 만들기

## 3.1 Slab Plate Bending 설정 확인

ADS 모델을 Gen으로 변환하기 전에 Plan 설정에서 `Diaphragm + Plate Bending` 적용 상태를 확인합니다. 기존 작업자료 기준으로 Slab는 유지하고 Level에 대한 Plate Bending 설정을 해제합니다.

모델과 ADS 버전에 따라 메뉴 위치와 표시 방식이 다를 수 있으므로 변환 전 대상 Plan을 다시 확인합니다.

## 3.2 ADS 모델 해석

설정 확인이 끝나면 ADS 모델을 해석합니다. 해석 오류, 불안정 또는 누락된 부재가 없는지 확인한 뒤 다음 단계로 진행합니다.

## 3.3 MGT 파일 Export

ADS에서 다음 메뉴를 이용해 Gen용 파일을 출력합니다.

```text
File → Export → Frame model to MIDAS/Gen
```

출력된 MGT 파일의 저장 위치와 파일명을 확인합니다. 변환에 사용한 ADS 원본과 MGT 파일이 서로 대응되도록 같은 프로젝트 폴더에 보관합니다.

### 완료 확인

- ADS 해석이 정상 완료되었는가?
- 필요한 Plan의 Plate Bending 설정을 확인했는가?
- Gen용 MGT 파일이 생성되었는가?
- 원본 모델과 Export 파일의 버전을 기록했는가?

# 4. Midas Gen 모델 정리

## 4.1 MGT 파일 Import

Midas Gen에서 ADS로부터 출력한 MGT 파일을 불러옵니다. Import 후 단위계, 절점, 부재, 재료, 단면, 하중과 경계조건을 우선 확인합니다.

## 4.2 지하외벽 모델링 확인

지하외벽은 기존 도면과 프로젝트 모델링 기준에 따라 생성하거나 수정합니다. 기존 작업자료에는 외곽에서 일정 거리 이격하여 모델링하는 일반 원칙과, 최외곽 구조체가 인접한 경우 도면에 맞추는 예외가 함께 제시되어 있습니다.

해당 기준은 프로젝트 조건에 따라 달라질 수 있으므로 담당 기술자의 확인을 받아 적용합니다.

## 4.3 불필요한 데이터 정리

변환 과정에서 생성된 불필요한 항목을 정리합니다. 기존 작업자료에서는 다음 항목을 주요 확인 대상으로 제시합니다.

- Boundary 정리 및 필요한 지점조건 재생성
- Rigid Link 확인 및 불필요 항목 삭제
- Nodal Mass 확인 및 기존 질량정보 정리
- 중복 또는 불필요한 절점 정리

정리 순서는 프로젝트에 맞게 조정할 수 있으나, 절점 정리는 다른 부재와 조건을 확인한 뒤 마지막에 수행하는 것을 원칙으로 합니다.

## 4.4 모델 검토

다음 항목을 확인합니다.

- 최하부 지점조건
- 다른 층에 잘못 지정된 지점 여부
- 질량과 강막 조건
- 부재 연결 및 중복 절점
- 층 정보와 높이
- 벽체, 보, 기둥, 연결보 및 전이부재
- 하중과 하중조합
- 해석 경고 및 불안정

모델 정리가 끝나면 PF3D Pre Processor에서 사용할 MGTX 또는 MGT 파일을 준비합니다.

# 5. PF3D Pre Processor v4.02

PF3D Pre Processor는 Midas Gen과 BeST에서 PF3D 입력에 필요한 자료를 추출하고 정리하는 전처리 프로그램입니다.

## 5.1 공통 설정

프로그램을 실행한 뒤 다음 항목을 확인합니다.

- 출력 파일명 접두어
- 결과 저장 폴더
- 프로젝트에 적용할 설정 프리셋
- 입력 파일의 버전과 경로

프로젝트별 설정은 JSON 프리셋으로 저장할 수 있습니다. 다른 프로젝트의 설정을 불러올 때에는 파일 경로와 적용 항목을 다시 확인합니다.

## 5.2 MGTX 추출

`MGTX 추출`에서는 Midas Gen의 `.mgtx` 또는 `.mgt` 파일을 선택하고 PF3D 입력에 필요한 항목을 생성합니다.

주요 출력 대상:

- Node
- Beam
- Column
- Wall
- Rotation Gage
- Axial Gage
- Embedded Beam
- Dead Load 관련 Nodal Load
- Live Load 관련 Nodal Load

필요한 항목을 선택한 뒤 실행하고, 생성된 파일의 개수와 저장 위치를 확인합니다.

## 5.3 Nodal Mass

Midas Gen의 Story Mass Table을 머리글과 함께 복사하여 Nodal Mass 입력 영역에 붙여넣습니다.

MGTX 파일을 함께 선택하면 층별 우발편심 정보를 연동할 수 있습니다. 편심 방향과 회전 보정 설정을 확인하고, MGTX의 층 수와 붙여넣은 Story Mass의 층 레벨이 일치하는지 확인합니다.

프로그램은 PF3D에서 사용할 Node 및 Nodal Mass 자료를 생성하며, 설정에 따라 우발편심 4방향 입력자료를 정리합니다.

## 5.4 Wall List 정리

BeST에서 출력한 Wall List 파일을 선택합니다. 프로그램은 후처리에서 사용할 수 있도록 벽체 자료를 정리하고 다음 형태의 결과를 생성합니다.

- 부재별 정리 TXT
- 벽체 단면 목록 CSV

생성 후 벽체명, 단면 두께, 재료정보와 배근정보가 원본 Wall List와 일치하는지 표본 검토합니다.

## 5.5 전처리 완료 확인

- 프로젝트명과 출력 접두어가 올바른가?
- 저장 폴더가 현재 프로젝트 폴더인가?
- MGTX 추출 항목이 모두 생성되었는가?
- Story Mass 층 수와 MGTX 층 레벨이 일치하는가?
- 우발편심 방향이 프로젝트 기준에 맞는가?
- Wall List의 부재명과 단면정보가 정상적으로 정리되었는가?

# 6. Perform-3D 기본 모델 작성

전처리에서 생성한 자료를 Perform-3D에 입력한 뒤 다음 순서로 모델을 구성하고 검토합니다.

## 6.1 Node 관련사항 확인

지점, 질량과 강막 조건을 확인합니다. 최하부층 이외의 위치에 잘못된 지점이 입력되지 않았는지 층별 표시 기능을 이용해 점검합니다.

## 6.2 재료 및 Gage 물성치 입력

프로젝트에 적용할 콘크리트, 철근과 Gage 관련 물성치를 입력합니다. 단위와 재료강도, 명명 규칙을 확인합니다.

## 6.3 전단벽 비선형 물성치 설정

전단벽의 비선형 특성과 관련 속성을 입력합니다. 벽체명과 단면정보가 전처리 결과와 일치해야 합니다.

## 6.4 탄성부재 유효강성 입력

보, 기둥과 전이보 등 탄성부재의 유효강성을 입력합니다. 반복 입력은 지정된 매크로를 이용할 수 있으며, 적용 전후 값을 표본 검토합니다.

## 6.5 연결보 FEMA 비선형 물성치 입력

연결보 또는 인방보의 특성을 확인하고 FEMA 기반 비선형 물성치를 입력합니다. 자동화 자료와 원본 부재 목록의 이름이 일치하는지 확인합니다.

## 6.6 층간변위 설정

해석 결과에서 층간변위를 확인할 수 있도록 기준점, 방향과 층 정보를 설정합니다.

## 6.7 층별 Structure Section 설정

결과 정리와 검토에 필요한 Structure Section을 층별로 설정합니다. 이름은 사내 표준 명명 규칙에 맞게 통일합니다.

## 6.8 Gage 입력

Axial 및 Rotation Gage 등 필요한 Gage를 입력하고 방향과 연결 상태를 확인합니다.

## 6.9 연결보 분리

연결보의 비선형 거동과 결과 확인에 필요한 분리 상태를 구성합니다.

## 6.10 Limit State 설정

부재와 Gage별 검토에 사용할 Limit State를 설정합니다. 명칭과 그룹은 후처리에서 식별할 수 있도록 표준 이름을 사용합니다.

## 6.11 P-Delta 효과 입력

프로젝트의 해석조건에 따라 P-Delta 효과를 설정하고 중력하중과 질량정보를 확인합니다.

## 6.12 지진파 입력

프로젝트에 사용할 지진파를 입력하고 방향, 단위, 스케일과 적용 Case를 확인합니다.

## 6.13 Load Case 설정

정적해석과 동적해석에 필요한 Load Case를 구성하고 각 입력자료가 올바른 Case에 연결되었는지 확인합니다.

## 6.14 Analysis 설정

해석 종류, 단계, 수렴조건과 저장할 결과를 설정합니다. 상세 설정값은 프로젝트 기준과 담당 기술자의 지시에 따릅니다.

## 6.15 Damping 설정

프로젝트의 해석 기준에 따라 감쇠 조건을 입력하고 적용 대상과 단위를 확인합니다.

## 6.16 횡하중 수직분포 입력

X방향과 Y방향의 층별 횡하중 가력패턴을 입력합니다. UX와 UY 자료에서 층 높이와 해당 방향 관성력을 확인하고, PF3D의 Load Pattern 형식에 맞게 적용합니다.

> 추후 추가: 각 단계별 Perform-3D 화면 캡처, 사내 표준 이름, 입력 예시와 검토 포인트.

# 7. AutoHotkey 및 매크로 사용

AutoHotkey는 Perform-3D에서 반복되는 입력과 결과 추출 작업을 보조하기 위해 사용합니다. 자동화 도구를 실행하기 전에 화면 배치, 해상도, 창 크기와 활성화된 탭이 매뉴얼의 기준 상태와 일치해야 합니다.

## 7.1 기본 원칙

- 매크로와 AutoHotkey의 버전을 확인합니다.
- Perform-3D와 작업용 Excel 창을 지정된 위치에 배치합니다.
- 화면 배율과 해상도를 임의로 변경하지 않습니다.
- 매크로를 실행하기 전에 시작 위치와 선택된 객체를 확인합니다.
- 실행 중 마우스와 키보드를 조작하지 않습니다.
- 전체 작업 전에 소규모 항목으로 정상 동작을 시험합니다.
- 자동 입력 후 결과를 반드시 표본 검토합니다.

## 7.2 입력자료 작성용 매크로

기존 작업자료의 매크로 입력은 다음 항목을 중심으로 구성되어 있습니다.

- 전단벽 면외강성 입력자료
- 탄성보·기둥·전이보 유효강성 입력자료
- 연결보 FEMA 비선형 물성치 입력자료
- 층별 Structure Section 및 반복 입력 보조

이전 K Design에서 생성하던 Wall Name 등의 자료는 PF3D Pre Processor의 출력자료로 대체합니다. 실제 파일 연결 규칙은 전처리 출력 형식이 확정된 후 화면 예시와 함께 추가합니다.

## 7.3 Section Cut 작업

Section Cut은 시간이 오래 걸릴 수 있으므로 프로젝트 일정과 모델 완성도를 고려하여 실행 시점을 결정합니다. 실행 전 대상 부재, 층, 방향과 저장 위치를 확인합니다.

## 7.4 결과 추출용 매크로

기존 결과정리 매크로는 다음 항목을 대상으로 합니다.

- 벽체 전단력
- 층 전단력
- 층간변위
- 보 부재력
- 기둥 부재력
- 인장변형률
- 축력

새 작업 흐름에서는 가능한 항목을 PF3D Post Processor로 통합하고, Post Processor에서 직접 처리하지 않는 화면 반복작업에만 AutoHotkey를 사용합니다.

## 7.5 매크로 오류 확인

매크로가 동작하지 않을 경우 다음을 확인합니다.

- Perform-3D 창 위치와 크기
- Windows 화면 배율
- 활성화된 메뉴와 결과 화면
- Excel 파일과 저장 경로
- 프로그램 버전
- 입력자료의 파일명과 시트명

오류가 반복되면 작업을 중단하고 수동으로 입력된 값이 없는지 확인한 뒤 프로그램을 다시 실행합니다.

# 8. 해석 실행 및 결과 Export

## 8.1 해석 전 최종 점검

- 지점, 질량과 강막
- 재료와 단면
- 비선형 부재와 Gage
- 유효강성
- Limit State
- P-Delta 및 감쇠
- 지진파, 방향과 스케일
- Load Case와 Analysis Series
- 횡하중 가력패턴
- 결과 저장 항목

## 8.2 해석 실행

우선 기본 모델에서 오류와 수렴 상태를 확인한 뒤 전체 Case를 실행합니다. 해석 중 발생한 경고와 오류는 별도로 기록하고, 모델 또는 해석조건을 수정했다면 변경 내용을 남깁니다.

## 8.3 결과 Export

PF3D Post Processor에서 사용할 결과를 TXT 또는 PDF로 Export합니다.

주요 결과:

- 층간변위 결과 TXT
- Pushover 성능곡선 결과 TXT
- Pushover 층간변위 결과 TXT
- 벽체 전단력 및 층 전단력 결과 TXT
- 벽체 전단변형각 결과 TXT
- Axial Strain Gage 결과 TXT
- 압축변형률·소성회전각·인방보 검토 PDF

파일명은 후처리 프로그램이 방향과 결과 종류를 식별할 수 있도록 사내 규칙에 맞게 작성합니다.

# 9. PF3D Post Processor v10.03

PF3D Post Processor는 Perform-3D 결과를 읽어 그래프, 검토표, Excel 파일과 보고서용 이미지를 생성합니다.

## 9.1 공통 설정

- 출력 파일명 접두어
- 결과 저장 폴더
- 프로젝트 또는 동 이름
- 입력 파일의 종류와 개수
- 적용할 허용기준과 설계값
- 저장된 설정 프리셋

실행 전 입력자료가 현재 프로젝트의 결과인지 확인합니다. 이전 프로젝트 설정을 불러온 경우 저장 경로와 기준값을 반드시 다시 확인합니다.

## 9.2 가력패턴

Midas Gen Story Shear 자료를 이용하여 Pushover 해석에 사용할 층별 관성력 분포를 정리합니다. X·Y방향의 층 이름, 높이와 가력값을 확인한 뒤 PF3D 입력용 자료와 그래프를 생성합니다.

## 9.3 층간변위

PF3D에서 Export한 층간변위 결과를 선택합니다. 프로그램은 지점과 방향별 결과를 정리하고 지진파별 응답, 평균 포락선과 허용 층간변위 기준을 포함한 Excel 및 PNG 그래프를 생성합니다.

## 9.4 정적해석

Pushover 성능곡선 TXT와 해당 층간변위 TXT를 함께 입력합니다. Story Mass, 응답스펙트럼과 설계밑면전단력 등 필요한 조건을 입력하면 성능곡선, 요구곡선, 성능점, 최대층간변위와 초과강도계수 관련 자료를 생성합니다.

생성 후 검증 시트의 계산값과 PF3D 화면의 Trial Points 정보를 대조합니다.

## 9.5 압축변형률·소성회전각·인방보

PF3D 결과 PDF를 선택하면 Analysis Series와 Limit State Group을 기준으로 필요한 페이지를 분류하고 보고서용 삽도와 캡션을 정리합니다.

파일명만으로 판단하지 않으므로 PDF 내부의 프로젝트명, Analysis Series와 결과 항목이 올바른지 확인합니다.

## 9.6 벽체전단력·층전단력

벽체 전단력 결과 TXT와 PF3D Pre Processor에서 만든 Wall List 정리 파일을 함께 입력합니다. 프로그램은 벽체별 전단 수요와 강도 검토표, 보강배근 검토자료와 층 전단력 그래프를 생성합니다.

자동추천 또는 직접입력 방식을 선택한 경우 적용된 기준과 D/C 목표를 확인하고, 대표 벽체의 계산 결과를 수동 검토합니다.

## 9.7 전단변형각

PF3D Usage Ratio 결과를 이용해 벽체 전단변형각을 방향별·층별로 정리하고 허용기준을 포함한 그래프를 생성합니다.

## 9.8 평균변형률

Axial Strain Gage 결과를 이용해 콘크리트 압축변형률과 철근 인장변형률을 정리합니다. 지진파별 결과와 평균값을 계산하고 방향별 층-변형률 그래프와 허용기준을 포함한 결과물을 생성합니다.

## 9.9 결과 저장 및 확인

생성된 Excel, PNG와 보고서 자료의 저장 위치를 확인합니다. 프로그램의 완료 메시지와 제외된 파일 목록을 검토하고 다음 항목을 표본 확인합니다.

- 대상 지진파 수와 방향
- 층 수와 층 이름
- 부재명과 Wall List 매칭
- 단위
- 평균 및 포락 방법
- 허용기준
- 그래프 축과 범례
- 누락된 결과와 인식하지 못한 파일
